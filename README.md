# Пульс инициатив

Приложение на Python для мониторинга выполнения плана по инициативам **Десятилетия науки и технологий**.
Оно собирает отчёты «план / факт», проверяет их, считает выполнение и прогноз на конец года и показывает всё на одном дашборде со светофором рисков.

Учебный проект. Заказчик — Центр сопровождения инициатив Десятилетия науки и технологий (Университет МИСИС).

## Проблема

Отчёт о выполнении плана ведётся в Word: 11 инициатив, 17 показателей, значения «план / факт» по годам.
Сводить его вручную долго, и в таком виде нельзя быстро ответить на вопросы:

- где отставание;
- где план устарел;
- каким цифрам нельзя доверять.

Реальные данные Центра показывают, что отставаний нет. Зато в 2026 году факт у **всех 17 показателей** превышает план в 1,5 раза и больше. Значит, главная задача мониторинга — не только поймать отставание, но и вовремя показать, что планы пора пересматривать.

## Решение

| Функция | Что делает |
| --- | --- |
| Импорт Word-отчёта | Переносит текущий отчёт Центра в базу: инициативы, показатели, единицы, признак «нарастающим итогом», «???» как «нет данных» |
| Excel-шаблон и загрузка | Шаблон с выпадающими списками; загрузка `.xlsx` / `.csv`, несколько файлов сразу |
| Проверка V-01…V-10 | Пустые значения, не числа, отрицательные числа, неверные годы и месяцы, неизвестные инициативы и показатели, дубли. Протокол ошибок можно скачать для куратора |
| Расчёты | % выполнения, прогноз на конец года, двусторонний светофор, медиана по инициативе, рейтинг |
| Качество данных | Флаги Q-1…Q-5: «факт = план», нет данных, инициатива отсутствует, резкий рост, уменьшение нарастающего итога |
| Дашборд | Главная карточка, статусы, светофор 12 инициатив, рейтинг, график план / факт по годам |
| Выгрузка | Сводный Excel: сводка, детализация, флаги, данные, параметры |
| Настройки | Пороги статусов, месяц данных текущего года, признаки «нарастающим итогом» и «разовое событие», демо-режим |

### Формулы

- Выполнение: **F / P × 100 %** (F — факт, P — план на год).
- Прогноз на конец года для обычного показателя: **Fc = F / M × 12**, где M — месяц, на который даны данные.
- Прогноз для показателя нарастающим итогом: **Fc = F₍прошлый год₎ + (F − F₍прошлый год₎) / M × 12**.
- Для закрытого года (M = 12) прогноз равен факту. Если данных меньше чем за 3 месяца, прогноз не считается.

### Статусы

Статус определяется по прогнозу в % от плана. Пороги меняются в «Настройках».

| Статус | Прогноз, % плана |
| --- | --- |
| Критично | меньше 80 |
| Риск | от 80 до 95 |
| В норме | от 95 до 150 |
| План занижен | 150 и больше |

Статус инициативы считается по **медиане** прогноза её показателей. Так один показатель, перевыполненный в 11 раз, не скрывает остальные.

## Данные

- `sample_data/otchet_plan_fakt_2022-2026.docx` — отчёт Центра «план / факт». Данные открытые, публикация согласована.
- **Допущение:** в отчёте не указана дата, на которую дан факт 2026 года. Принято, что это **30.06.2026** (M = 6). При такой дате прогноз 2026 года больше факта 2025 года у всех показателей. Месяц меняется в «Настройках».
- В 2026 году у четырёх показателей факт равен плану. Куратор подтвердил, что это реальные значения, поэтому при загрузке отчёта Центра они отмечаются как подтверждённые.
- **Демо-данные** (`pulse/demo.py`) — синтетические, выдуманные. Они нужны, чтобы показать все цвета светофора и флаги качества. В интерфейсе демо-режим отмечен баннером «ДЕМО».

## Технологии

Python 3.10+, Streamlit, pandas, SQLite (встроен в Python), plotly, openpyxl, python-docx, pytest. Все библиотеки бесплатные. Внешних и платных API нет, данные хранятся локально в `data/pulse.db`.

## Запуск

```bash
git clone https://github.com/<ваш-логин>/pulse-initiatives.git
cd pulse-initiatives
python -m venv .venv
# Windows:  .venv\Scripts\activate
# macOS / Linux:  source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере по адресу http://localhost:8501.

При первом запуске база пустая. На дашборде нажмите «Загрузить отчёт Центра 2022–2026» или «Загрузить демо-данные».

Тесты бизнес-логики:

```bash
pytest
```

## Фирменный стиль

Синие и голубые цвета наука.рф, градиенты и логотип Десятилетия науки и технологий. Использование логотипа согласовано с Центром.
Цвета светофора (зелёный, оранжевый, красный) — сигнальные. Каждый статус дублируется иконкой и подписью.

## Ограничения MVP

- Один пользователь, локальный запуск, без авторизации.
- Прогноз линейный, без учёта сезонности. Разовые события можно отметить в «Настройках».
- В бесплатном облаке Streamlit база может стираться при перезапуске. Для облачной демонстрации используйте загрузку отчёта или демо-данных кнопкой.
